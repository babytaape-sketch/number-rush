# Предварительная шкала оценки полного российского номера

Статус: исследовательское предложение, НЕ runtime-правило. Не изменяет генератор, вероятности выпадения, награды или действующие уровни игры.

## 1. Не сводить всё к одному числу

Каждому номеру присваивается вектор независимых измерений:

- **S — структурная редкость**: насколько необычен класс цифрового и буквенного рисунка в пространстве допустимых комбинаций.
- **V — визуальная выразительность**: насколько легко рисунок заметить и запомнить.
- **M — рыночный сигнал**: есть ли подтверждённая надбавка в сопоставимых объявлениях.
- **H — историческая доказательность**: насколько надёжно подтверждена ассоциация буквенной серии именно для этого региона/периода.
- **R — региональный/контекстный признак**: точное совпадение цифр с кодом региона, визуальное совпадение с нулями или контекстно значимый код.
- **C — целостная комбинация**: особое совпадение нескольких признаков в одном полном номере (например, А777АА), которое фиксируется отдельно, без перемножения премий.

Каждое измерение хранится отдельно. Не суммировать и не перемножать M, H и S в общий «рыночный коэффициент».

## 2. Шкала S: структурная редкость

S оценивает частоту класса рисунка, а не субъективную красоту.

| Уровень | Критерий |
|---|---|
| S0 — обычный | Нет выделенного структурного паттерна |
| S1 — заметный | Один простой повтор/соседняя пара, круглый десяток или простой палиндром |
| S2 — редкий класс | Тройка одинаковых букв или цифр; первая десятка |
| S3 — исключительный класс | Сочетание нескольких независимых структурных признаков без двойного счёта |
| S4 — уникальная конструкция | Очень узкий класс полного совпадения, подтверждённый подсчётом допустимых комбинаций и отдельной проверкой |

Важная оговорка: конкретные 777 и 123 имеют одинаковую вероятность как точные трёхзначные строки при равномерной генерации (по 1/1000). Различается частота класса: «три одинаковые цифры» — 10 из 1000, а строго возрастающие тройки с шагом 1 — 8 из 1000 (012–789). Рыночная премия не меняет эту математическую вероятность. Уточнять подсчёты с учётом реально разрешённых/выдаваемых сочетаний до финальной реализации.

Для букв: ровно три одинаковые буквы — 12 из 1728; зеркальные формы ABA с A≠B — 132 из 1728. Конкретная последовательность ААА и конкретная последовательность АВА имеют вероятность 1/1728 при равномерном выборе букв.

## 3. Шкала V: визуальная выразительность

| Уровень | Критерий |
|---|---|
| V0 | Нет очевидного рисунка |
| V1 | Одна простая пара или округлённое окончание |
| V2 | Палиндром, последовательность, круглая сотня, зеркальная буквенная тройка, читаемая словесная тройка |
| V3 | Три одинаковых цифры/буквы либо сильный симметричный рисунок |
| V4 | Согласованный рисунок цифр и букв (например, А777АА), легко распознаваемый целиком |

Не считать palindrome_outer и pair_outer двумя бонусами. Тройка одинаковых цифр уже включает парные совпадения. 001/007 — первая десятка и визуально сильные формы, но не triple_same.

## 4. Шкала M: рыночный сигнал

| Уровень | Критерий |
|---|---|
| M0 | Нет достаточного рыночного свидетельства |
| M1 | Небольшая надбавка в одном источнике или ориентир около 1.1–1.5x |
| M2 | Повторяемый умеренный сигнал примерно 1.5–3x в сопоставимых выборках |
| M3 | Сильный сигнал примерно 3–5x |
| M4 | Очень сильный сигнал выше 5x |

Назначать M только при наличии описанного контроля по региону и остальным символам. При единичном/смещённом источнике ставить пометку provisional, не повышать класс автоматически. Наблюдаемые множители относятся к ценам объявлений, а не к закрытым сделкам. Региональные/буквенные эффекты не переносить на всю страну без проверки.

Примеры рыночных ориентиров из Gosnomerus (август 2026): 777 ~7x (M4), 001 ~5.1x (M4), 888 ~4x (M3), 555 ~3.8x (M3), 123 ~1.2x (M1). Это рыночная ось, не структурная редкость.

## 5. Шкала H: история и происхождение

| Уровень | Критерий |
|---|---|
| H0 | Сведений нет |
| H1 | Слух, форумная версия, неподтверждённое утверждение |
| H2 | Один вторичный источник или неоднозначные/конфликтующие сведения |
| H3 | Несколько независимых вторичных источников с совпадающей версией |
| H4 | Надёжная публикация/документ, подтверждающий серию, регион и период |

Исторический статус должен совпадать по трём ключам: серия + регион + период. Если совпадает только буквенная тройка, не переносить H на номер. Даже H4 — историческая ассоциация, а не доказательство текущей принадлежности автомобиля к ведомству. Для игровых бонусов H1/H2 не использовать.

## 6. Шкала R: регион

- R_exact: цифровая комбинация совпадает с кодом региона по точному правилу (например, 077 с 77 только если явно принято такое правило нормализации; хранить исходную и нормализованную формы).
- R_zero_padded_visual: совпадение только визуальное после добавления/снятия ведущего нуля (например, 070/70); это не математическое равенство.
- R_context: код региона сам по себе имеет культурную/рыночную значимость, подтверждённую отдельными данными.
- R_none: значимой связи нет.

Регион не получает бонус только за «большой» или узнаваемый код. Проверять допустимость кода и исторический период отдельно.

## 7. Шкала C: целостное совпадение

C фиксирует композицию, а не новый самостоятельный источник ценности:
- C0 — независимые признаки не образуют цельного рисунка;
- C1 — два согласованных визуальных элемента;
- C2 — сильная согласованность цифр и букв (например, А777АА);
- C3 — согласованность плюс подтверждённый региональный/исторический контекст.

C не прибавляется арифметически к S/V/M/H. Это отдельная метка. Не делать вывод о цене полного номера из произведения отдельных множителей.

## 8. Как назначать итоговую игровую редкость позднее

1. Сначала вычислить S по точным частотам допустимых классов.
2. Затем V по визуальной рубрике.
3. M использовать как ограниченный фактор пользовательского спроса, а не как вероятность.
4. H учитывать только при H3/H4 и точном совпадении серии, региона, периода.
5. C использовать как композиционную метку, без двойного счёта.
6. Игровой tier выбирать через отдельную таблицу решений и тест на экономику игры; не назначать Mythic автоматически за 777, 888, 001, ААА или слуховую спецсерию.

До реализации нужны: аудит точных частот всех паттернов, верификация допустимых регионов/серий по периодам, большая выборка полных объявлений с дедупликацией, и проверка на репрезентативности за пределами Москвы/МО.

## 9. Тестовые примеры и ожидаемое поведение

- А 777 АА 77: S2 для triple digits + triple letters; V4; M4 для цифрового паттерна по одному matched study; H0 без точной подтверждённой истории серии/региона; C2. Не автоматически Mythic.
- А 001 АА 77: S2 как первая десятка; V3; M4 как рыночный ориентир; H0; C1. Не triple digits.
- А 123 ВЕ 77: S1/S2 только после формального подсчёта последовательностей; V2; M1; лексическое/буквенное значение требует самостоятельной проверки.
- А 070 АА 70: R_zero_padded_visual, не R_exact; визуальная связь отмечается, но не приравнивается к совпадению региона.
- Е 911 КХ 77 (буквенная серия ЕКХ): цифровой рыночный сигнал около 1.9x (M2); H3 для исторической ассоциации ЕКХ/77 по текущему каталогу, но пометка историческая и не текущий статус; итог зависит от периода/доказательств конкретной записи.
- А 123 АА 77: рыночный сигнал цифровой 123 умеренный/слабый (M1); буквы ААА структурно повторяющиеся (S2/V3); не суммировать два признака в «легендарный» автоматически.

Примеры иллюстративные, не подтверждают фактическую выдачу конкретного номера.

## 10. Статус

Это проект шкалы для обсуждения и последующего тестирования. Никакие production-файлы, генератор, вероятности RARITIES, игровые награды или UI не менялись.
